# BDHPD benchmark reproduction

This directory contains the BDHPD model and the code needed to run it with this benchmark's fixed splits. It was adapted from `/data/storage1t/gits/BDHPD` at revision `cc62c56b22fd646ac2b5e7ca29b80eeb8f47d0b5`. The original BDHPD repository did not include a license file; confirm its redistribution terms before publishing this integration outside the private PD-early repository.

## 1. Prepare inputs

Follow the [main benchmark guide](../README.md#2-prepare-audio) to prepare mono 16 kHz WAVs and [generate local filelists](../README.md#3-generate-and-validate-local-filelists). BDHPD reads the `AUDIOFILE` WAVs directly. Its WavLM and wavelet features are computed by the data loader and model; there is no separate feature extraction command. The WavLM weights named in `configs/config_early_maxf1.yaml` must be available in the model cache or downloadable on the first run.

Install the model dependencies in a Python 3.10 environment:

```bash
pip install -r bdhpd/requirements.txt
```

Use a PyTorch and torchaudio build matching your CUDA installation if the listed wheels are unsuitable.

## 2. Select an experiment

All launchers use seeds 42–46, five folds, and the same task directories as the benchmark. Public settings cover DDK, sustained vowel /a/, and Sentence. The Private track covers DDK and vowel only.

| Launcher | Training TSV | Validation / test |
|---|---|---|
| `run_5seeds_all.sh` | `train.tsv` | EarlyPD |
| `run_5seeds_allsubset.sh` | `train_allPDsubset.tsv` | EarlyPD |
| `run_5seeds_early.sh` | `train_earlybalance.tsv` | EarlyPD |
| `run_5seeds_earlypersp.sh` | `train_early_persp.tsv` in a separate private root | EarlyPD |
| `run_5seeds_allPDval.sh` | `train.tsv` | All-stage PD |

Each launcher selects the matching validation and test TSVs listed in the [main guide](../README.md#4-benchmark-experiment-settings). The integrated All-stage launcher writes to its own output directory; the old source launcher accidentally pointed at the AllPD-subset directory.

## 3. Run training

Set `SPLITS_ROOT` to the local filelists generated by the main guide. For example, inspect the commands, then run all tasks, five runs, and five folds:

```bash
DRY_RUN=1 SPLITS_ROOT="/path/to/runtime_splits" bash bdhpd/runs/run_5seeds_all.sh
SPLITS_ROOT="/path/to/runtime_splits" CUDA_VISIBLE_DEVICES=0 bash bdhpd/runs/run_5seeds_all.sh
```

For a first run of one fold, set `NUM_RUNS=1`, `TASK_DIR=folds_tsv_DDK_ANALYSIS_PATAKA`, and `FOLD=1`. Use `OUTPUT_ROOT` to choose another setting output directory. The default is:

```text
outputs/bdhpd/run_5seeds_all/<task>/run_<1-5>/fold_<1-5>/
```

The training script selects the best model using validation ROC AUC, chooses a positive-class F1 threshold on validation, and tests with that threshold. Each fold writes `Neurovoz_and_PC_GITA_detailed_results.tsv` with a `probability` column and `tuned_thresholds.json`. It also writes checkpoints under the output directory; these are not included in the archived results.

## 4. Private track

Prepare private WAVs in the same audio format and use unique speaker IDs. The [private training-list generator](../reca_pd/README.md#6-add-private-training-data) creates `train_early_persp.tsv` under a separate root while leaving public validation and test lists unchanged. Then run:

```bash
SPLITS_ROOT="/path/to/runtime_splits" \
TRAIN_SPLITS_ROOT="/path/to/private_training_splits" \
CUDA_VISIBLE_DEVICES=0 bash bdhpd/runs/run_5seeds_earlypersp.sh
```

## 5. Evaluate results

Run the shared evaluators on one completed setting:

```bash
SUBJECT_SAMPLE_SALT_ROOT="/data/storage1t/projects/early/BDHPD" \
  ./evals/run_all.sh outputs/bdhpd/run_5seeds_all
```

The script writes the main, gender, and subject-level aggregates under each task directory. The `SUBJECT_SAMPLE_SALT_ROOT` string reproduces the historical Sentence k=3/k=10 sampling and does not need to point to an existing directory. The archived text results are in [`results/bdhpd/experiments/`](../results/bdhpd/experiments/). Their `AUDIOFILE` values record the original server paths; use locally generated `runtime_splits/` when training on another machine. Four settings contain complete per-recording results and were reaggregated with `evals/`. The historical AllPD-subset run has 75 fold metrics in `runallsub.log` and reproduces the paper's F1/AUC values, but its prediction TSVs and checkpoints are unavailable; see its [log-only record](../results/bdhpd/experiments/run_5seeds_allsubset/README.md).
